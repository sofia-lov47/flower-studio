# Студия цветов «Лаванда»

Учебный сайт цветочной студии. Основа сайта подготовлена в лабораторной работе № 4. В лабораторной работе № 5 продолжена работа с проектом с использованием Git, GitHub и ИИ-ассистента.

## О сайте

Сайт содержит каталог из шести букетов, информацию о студии, услугах и доставке, отзывы, частые вопросы и контакты.

Использованы HTML, CSS и JavaScript. Разметка, стили и скрипты находятся в файле index.html, изображения — в папке images.

Для локального просмотра достаточно открыть index.html в браузере.

## Изменения в лабораторной работе № 5

- В main добавлена кнопка «Наверх», которая появляется после прокрутки страницы.
- В ветке site-improvements добавлен блок «Частые вопросы».
- В ветке photos уточнено альтернативное описание изображения букета «Прованс».
- Изменения из обеих веток объединены с main локальными командами Git.
- Основная ветка и две дополнительные ветки загружены на GitHub с сохранением истории коммитов.

## Использование ИИ

Для подготовки сайта и изображений использовались инструменты ИИ. Кнопка «Наверх» и блок «Частые вопросы» добавлены с помощью SourceCraft Code Assistant. Часть последующих действий выполнена вручную в редакторе и терминале VS Code.

Изображения букетов созданы с помощью генерации изображений. Дополнительные сведения приведены в IMAGE_SOURCES.md.

## Учебные данные

Контакты, цены и отзывы приведены для демонстрации. Форма заказа не отправляет данные.
