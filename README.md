# Студия цветов Лаванда

Учебный проект лабораторной работы №5. HTML, CSS и JavaScript находятся в index.html; сайт открывается без установки зависимостей.

Адрес GitHub Pages: https://sofialov47-eng.github.io/flower-studio/

## История проекта

- main — основная версия сайта.
- site-improvements — подстановка выбранного букета и проверка телефона.
- photos — первоначальные три фотографии в каталоге.
- Изменения объединены в main через pull request №1.

## Работа агента

Пользователь поручил агенту Codex выполнить работу по методичке на основе flower_studio. Агент конкретизировал задачи: заменить три эмодзи локальными фотографиями nezhnost.jpg, provans.jpg и sunny-day.jpg, добавить alt и отложенную загрузку; при заказе подставлять название букета и проверять телефон. Снимки до и после сохранены отдельно для отчёта.

## Изображения

Итоговая локальная версия содержит шесть фотореалистичных изображений, созданных встроенным ImageGen. Происхождение: [IMAGE_SOURCES.md](IMAGE_SOURCES.md). Полные запросы: [images/GENERATION_PROMPTS.md](images/GENERATION_PROMPTS.md). Все шесть JPEG хранятся локально.

Обновление всех шести изображений пока не загружено в GitHub: там предыдущая версия. Публикация Pages не завершена, адрес возвращал 404; GitHub отказал включить Actions.

## Проверка

Проверены отображение фотографий, выбор букета, ошибка при коротком телефоне и учебное подтверждение формы. Форма не отправляет данные. Контакты, цены, отзывы и сведения о студии демонстрационные.
