# Студия цветов «Лаванда»

Учебный сайт цветочной студии. Основа сайта подготовлена в лабораторной работе № 4. В лабораторной работе № 5 продолжена работа с проектом с использованием Git, GitHub и ИИ-ассистента.

## Просмотр сайта

Опубликованный сайт: https://sofia-lov47.github.io/flower-studio/

Для локального просмотра откройте index.html. Папка images должна находиться рядом с ним.

## О сайте

Сайт содержит каталог из шести букетов, информацию о студии, услугах и доставке, отзывы, частые вопросы и контакты.

Использованы HTML, CSS и JavaScript. Разметка, стили и скрипты находятся в index.html, изображения — в папке images.

## Изменения в лабораторной работе № 5

- В main добавлена кнопка «Наверх», которая появляется после прокрутки страницы.
- В ветке site-improvements добавлен блок «Частые вопросы».
- В ветке photos уточнено альтернативное описание изображения букета «Прованс».
- В ветке photo-update повторно выполнено учебное задание по замене эмодзи изображениями во всех шести карточках. Подготовительная версия с эмодзи и результат замены сохранены отдельными коммитами.
- Для изображений добавлены содержательные alt-описания и отложенная загрузка.
- Изменения из дополнительных веток объединены с main локальными командами Git.
- Все четыре ветки загружены на GitHub с сохранением истории коммитов.
- Сайт опубликован через GitHub Pages.

## Использование ИИ

Кнопка «Наверх», блок «Частые вопросы» и повторная замена эмодзи изображениями выполнены с помощью SourceCraft Code Assistant. Команды сохранения изменений, слияния веток и отправки на GitHub выполнялись в терминале VS Code.

Изображения букетов созданы с помощью генерации изображений. Дополнительные сведения приведены в IMAGE_SOURCES.md.

## Учебные данные

Контакты, цены и отзывы приведены для демонстрации. Форма заказа не отправляет данные.
